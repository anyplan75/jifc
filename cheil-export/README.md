# 서귀포제일교회 (CHEIL) 실시간 통역 — export

이 폴더는 `anyplan75/cheil` 저장소용 배포본입니다.
Cloud Agent가 `cheil` 저장소에 직접 push할 권한이 없어 `jifc`에 임시로 보관합니다.

## cheil 저장소에 넣는 방법
1. Cursor에서 **anyplan75/cheil** 저장소로 Cloud Agent를 새로 연다
2. 이 폴더(`cheil-export`) 내용을 cheil 루트로 복사해 달라고 요청한다
   또는 GitHub에서 이 브랜치의 `cheil-export/` 파일을 cheil로 옮긴다
3. Pages: Deploy from a branch → `pages` 또는 `main` / root

Firebase 경로: `/cheil` (jifc와 데이터 분리)
